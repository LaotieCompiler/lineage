方法与限制

  • DDL：5 个 .osql 文件、221 张表载入元数据目录；ODPS 的 LIFECYCLE 在载入前剥离，使用 Hive 方言解析。
  • SQL 预处理：${bizdate} 等调度变量替换为固定日期；ODPS 脚本变量 @var := SELECT … 内联为派生表。
  • 元数据修补：对 ColumnNotFoundException 中列出的物理表补齐被引用字段，共 4 个字段，保证依赖可解析。
  • COUNT(*)：本次分析前修正了解析器把 COUNT(*) 当作 SELECT * 的问题；否则聚合查询会虚构出全表字段边。
  • 未解析语句：剩余失败集中在 ODPS 专有构造——LATERAL VIEW 输出列、TRANS_COLS 表函数、VALUES 表构造器，以及嵌套作用域中重复别名；这些语句不产生字段边。
  • 口径：表级边为直接依赖（沿临时表追溯到第一个物理表），保留 DWD/DWS 中间层；字段级边为端到端闭包，只保留最终物理源字段。
